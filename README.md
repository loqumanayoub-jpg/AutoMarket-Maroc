AutoMarket Maroc - Single Page Car Dealership Template

This is a standalone single-page template for a car dealership named "AutoMarket Maroc".

Structure:
- index.html - single page SPA
- css/style.css - styling
- js/config.js - configuration values
- js/cars.js - car data
- js/script.js - main app script
- images/ - placeholder images (logo, hero, cars)

How to use:
Open index.html in a browser. Edit js/config.js to update contact details and paths as needed. Edit js/cars.js to add or modify vehicle listings.
